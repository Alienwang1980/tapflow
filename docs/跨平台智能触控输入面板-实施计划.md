## Phase 7-8 — 架构重写 (2026-07-08)

### 成果
彻底重写渲染架构，从手动跨设备像素计算改为 CSS `transform: scale()` 方案。

**核心技术变更：**
- 两端统一使用固定设备画布 (834×1210)，CSS `scale()` 自适应视口
- canvasX/Y 统一为 grid cells 单位，编辑器 pan 和 iPad 渲染完全一致
- 字体大小等比缩放 (`cs × 0.25`)
- 按钮间距标准化 (3px gap)

**修复的关键 Bug：**
- iPad 空白页 (JS `catch` 无配对 `try`)
- 编辑器 Pan 后保存→iPad 不响应 (scale 不一致)
- 编辑器按钮拖拽消失 (onDropCell/onDropKey 缺失)
- 字体不随 zoom 缩放 (CSS 硬编码 font-size)

### 当前架构
```
固定画布 834×1210
├── CSS transform: scale() → 自适应任何屏幕
├── Keys: (col + padX + panX) × cellSize
├── canvasX/Y: grid cells, 两端共享
├── WebSocket: 实时同步
└── REST: 降级加载
```
