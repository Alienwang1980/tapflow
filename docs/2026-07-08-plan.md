## Phase A: F39+F41 — 0.25 格精度 + 网格间距

| 文件 | 改动 |
|------|------|
| `server/profiles/_default_template.json` | 加 `"gap": 0` |
| `server/profile_manager.py` | migration: col/row/w/h 兼容 float，profile 缺 gap → 补 0 |
| `client/editor.html` | 渲染数学重写，拖拽吸附 0.25，缩放吸附 0.25，左右双向缩放 + 碰撞检测 |
| `client/index.html` | iPad 同步渲染数学 |

**渲染公式:**
```
px = cellSize + gap
x = (col + canvasX) * px + deviceWidth / 2
y = (row + canvasY) * px + deviceHeight / 2
w_px = w * cellSize + (w - 1) * gap
h_px = h * cellSize + (h - 1) * gap
```

**gap=0 等价性：**
```
旧: x = (col + padX + cx) * cs = col*cs + dw/(2*cs)*cs + cx*cs = col*cs + dw/2 + cx*cs
新: x = (col + cx) * (cs + 0) + dw/2 = col*cs + cx*cs + dw/2
✅ 等价
```

**碰撞检测:** 两 key AABB 不重叠（col, row, w, h 做矩形交检测），冲突 snap 到最近合法位置

**重启:** server → copy `profile_manager.py` 到 bundle → kill + reopen → curl 验证

**Commit message:** `feat(F39,F41): 0.25 grid precision + gap spacing for editor and iPad`

**验证:** 功能基线 #1-#18 + gap=0 旧 profile 位置不变 + 拖拽吸附 0.25 + resize 吸附 0.25

## Phase C: F42+F38 — 成组/解组 + Undo/Redo

| 文件 | 改动 |
|------|------|
| `client/editor.html` | Group/Ungroup 按钮，组虚线边框，统一移动；Undo stack（200 上限），Ctrl+Z/Ctrl+Shift+Z |
| `server/profile_manager.py` | migration: key 缺 `groupId` → `null`，profile 缺 `groups` → `[]` |

**数据模型变更:**
```json
// key 新增
"groupId": null,

// profile 根新增
"groups": [{"id": "g1", "name": "Group 1"}]
```

**Undo entry 结构:**
```js
{
  type: "move"|"resize"|"add"|"delete"|"property"|"group"|"ungroup",
  keys: [{id, col, row, w, h, color, label, value, groupId, ...}],
  ts: Date.now()
}
```

**撤销类型:**

| 操作 | undo |
|------|------|
| 移动 key | 恢复 col/row |
| 缩放 key | 恢复 w/h/col |
| 添加 key | 删除 key |
| 删除 key | 重新创建 key（用存储的 id） |
| 修改属性 | 恢复旧属性值 |
| 成组 | 解组（保留 group 对象） |
| 解组 | 重新赋予旧 groupId |

**重启:** server → copy + kill + reopen

**Commit message:** `feat(F42,F38): group/ungroup + undo/redo (200-step stack, Ctrl+Z)`

**验证:** 功能基线 #1-#18 + Group/Ungroup + 组统一移动 + Ctrl+Z/Ctrl+Shift+Z
