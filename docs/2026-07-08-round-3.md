## Phase 1: Bug 修复 + 小改动

### B1-r3 — ftb 位置修复

**现状**: `rr()` 中 ftb 使用 `right=` 和 `left="auto"`，但浏览器渲染后仍在中心。
**根因**: `right` 需要 px 值，当前计算 `cw-ox-(dw*scale)` 可能不正确。

**修复方案**:
```js
// rr() 中 ftb 定位，放在 frame 右上角外侧
const ox=(cw-dw*scale)/2, oy=(ch-dh*scale)/2;
const ftb=document.getElementById("ftb");
ftb.style.cssText=`
  position:absolute;
  right:${ox}px;
  top:${Math.max(0,oy-22)}px;
  z-index:10;
`;
```
去除 `ftb.style.left/ftb.style.width` 设置，改为 `cssText` 一次性覆盖。

**`saveAsGroup()`**:
```js
function saveAsGroup(){
  const name = prompt("Group name:", "Group " + ((profile.groups?.length||0) + 1));
  if(!name) return;
  const gid = "g_" + Date.now();
  if(!profile.groups) profile.groups = [];
  profile.groups.push({id: gid, name: name});
  cp_().keys.forEach(k => { if(selKeys.has(k.id)) k.groupId = gid; });
  dirty = true; renderAll();
}
```

**`selectGroup(gid)`**:
```js
function selectGroup(gid){
  selKeys.clear();
  cp_().keys.forEach(k => { if(k.groupId === gid) selKeys.add(k.id); });
  selKey = null; rr(); rpr();
}
```

**`deleteGroup(gid)`**: 解组，不清除按键
```js
function deleteGroup(gid){
  if(!confirm("Ungroup this group?")) return;
  cp_().keys.forEach(k => { if(k.groupId === gid) k.groupId = null; });
  profile.groups = profile.groups.filter(g => g.id !== gid);
  dirty = true; renderAll();
}
```
