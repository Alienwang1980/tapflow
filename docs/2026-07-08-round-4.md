## Phase 1: 网格+hover — G1+G2

### G1 — 网格跟随 pan

**当前**:
```js
canvas.style.backgroundSize=gridPx+"px "+gridPx+"px";
```
**修改**: 加 `backgroundPosition`:
```js
canvas.style.backgroundSize=gridPx+"px "+gridPx+"px";
canvas.style.backgroundPosition=(-panX*cpx%gridPx)+"px "+(-panY*cpx%gridPx)+"px";
```
`panX*cpx` 是画布偏移的像素量。取模 `gridPx` 使背景无缝循环。

### G2 — hover 高亮修复

**当前**: `gh2` 变量名、CSS 初始隐藏
**修改**:
1. 统一变量名 `gh2` → `gh`（HTML id 是 `gh`，不是 `gh2`）
2. 去重 CSS `.gh`（两次定义）
3. 确保 `gh.style.display="block"` 不被覆盖

```js
const gh=document.getElementById("gh");
gh.style.display="block";gh.style.left=(csx-crect.left)+"px";
gh.style.top=(csy-crect.top)+"px";gh.style.width=csw+"px";gh.style.height=csw+"px";
```
